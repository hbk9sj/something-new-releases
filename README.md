# something-new-releases

Finished carousel slides for the Instagram account @madprompter ("Something New"), seven
1080 × 1350 PNGs per post in `<date>-<slot>/01..07.png`. Buffer fetches these by raw URL when a
post publishes, so a folder stays here until its post has gone out.

`nueravix-x/` holds the scripts and fixed rules of the daily routine for the X account @decodingsi (formerly @nueraviX); see
`nueravix-x/CLAUDE.md`. Its proof images are pushed to the routine's own `claude/` branches, never here.
